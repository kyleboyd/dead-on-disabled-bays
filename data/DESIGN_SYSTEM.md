# Dead on Disabled Bays — product design system

Supplied by the project owner from Figma on 13 November 2026. Kept as written.

Build a map-first civic reporting experience using these rules:

## BRAND

- Product name: Dead on Disabled Bays
- Voice: direct, respectful, calm, useful. Never shame disabled people or trivialise access.
- Primary action colour: Access Blue #0A58BF.
- Dark surface and high-emphasis text: Civic Navy #093773.
- Information accent: Wayfinding Blue #0468BF.
- Attention only: Signal Yellow #F1F20C with #111820 text.
- Canvas: #FFFFFF; subtle surface: #F2F2F2.

## TYPE & LAYOUT

- Use Inter, Arial, or a legible system sans-serif.
- Body text minimum 16px / 24px. Never use text below 14px.
- Headlines use 700 weight, tight line-height, sentence case.
- Use a 4px spacing grid; core steps: 4, 8, 12, 16, 24, 32, 48, 64.
- Mobile-first. Minimum interactive target 44×44px.

## COMPONENTS

- Primary buttons are solid #0A58BF with white text; focus ring #111820 + white offset.
- Avoid pill-shaped containers except status tags.
- Form labels are always visible above controls; never rely on placeholders.
- Reports show status with text + icon + colour, never colour alone.
- Map pins must have a non-map list alternative.
- Error messages explain what happened and how to fix it.

## ACCESSIBILITY

- Meet WCAG 2.2 AA. Text contrast ≥4.5:1; large text and UI boundaries ≥3:1.
- All flows work with keyboard, screen reader, zoom to 200%, and reduced motion.
- Keep heading order logical and announce async status changes.
- Use plain language and put the outcome before supporting detail.
